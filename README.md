
 STAND

Description
STAND is a 3D-designed stand created using Onshape. It is designed to provide a stable and practical support for holding items in a convenient position. The design focuses on simplicity, functionality, and efficient use of materials. Its structure is modeled in 3D to visualize the final product and make modifications easier before manufacturing.

## Inspiration / Motivation
I recently bought a graphic designing tablet, and I wanted to make something really cool for my tab.

## Tools and Technologies Used
- Onshape — 3D CAD design
- printables - for uploading
